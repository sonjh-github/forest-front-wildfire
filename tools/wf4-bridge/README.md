# 전광판 연결 도구

산불 서비스 **현장 기상 → 기상정보 전광판 → 연결 도구 설치·설정**을 펼칩니다.
사용하는 운영체제를 선택하고 Node.js 26.13.1을 설치한 뒤 연결 도구 ZIP을 다운로드합니다.
Node.js 공식 설치: https://nodejs.org/en/download/archive/v26.13.1
실행기는 설치된 Node.js가 26.13.1인지 확인합니다. 다른 버전이면 설치 안내를 표시합니다.
ZIP 전체를 압축 해제한 뒤 Windows는 `start.cmd`를 더블클릭합니다.
macOS·Linux는 압축을 푼 폴더의 터미널에서 `sh ./start.sh`를 실행합니다.
외부 패키지 설치나 관리자 권한은 필요하지 않습니다. 실행 창은 열어 둡니다.
Node.js 설치 전부터 열어 둔 터미널에는 설치 경로가 반영되지 않을 수 있으므로 창을 새로 엽니다.
도구 다운로드 주소: https://wildfire.forest.tobeunicorn.kr/wf4-bridge.zip
대시보드의 **연결 도구 실행 확인**에서 실행 여부를 확인합니다. 이 버튼은 전광판에 명령을 보내지 않습니다.
PC를 **WF4_441bf6eef410** Wi-Fi에 연결하고 산불 서비스의 현장 기상 화면에서 **장치 인식**을 누릅니다.
대시보드의 대상은 이 장치로 고정되어 있습니다. 장치 조회와 매번 송신 직전에 보드가 응답한 Wi-Fi MAC을 확인합니다.
식별값이 다르거나 확인되지 않으면 화면 설정·프로그램 명령을 보내지 않습니다. Wi-Fi를 자동 전환하지 않습니다.
브라우저에서 로컬 네트워크 접근을 물으면 사용자가 허용해야 합니다.
이후 새 기상정보가 들어오면 나눔스퀘어 한 줄을 가로 네 장(256×32)에 왼쪽으로 이동시키는 프로그램을 전송합니다.

인터넷과 보드 Wi-Fi가 모두 필요한 구성입니다. Wi-Fi 어댑터가 하나라면 인터넷은 유선 등 다른 연결을 사용해야 합니다.
도구는 `127.0.0.1:8790`에서만 수신하며, 운영 화면 `https://wildfire.forest.tobeunicorn.kr`만 허용합니다.
장치 인식은 조회 명령만 보냅니다. 전송은 현재 표시 프로그램을 교체합니다.
프로그램 전체를 한 번 전송하면 프레임 재생은 보드가 처리합니다. 매 프레임을 다시 업로드하지 않습니다.
문구는 1픽셀씩 25ms 간격으로 이동합니다. 이전 4픽셀·100ms와 같은 초당 40픽셀 속도입니다.
1픽셀 이동을 유지하며 2MB 안에 들어가지 않는 긴 문구는 오류로 안내합니다. 최초 프로그램 송신에는 최대 2분을 기다립니다.
원본 송수신 로그는 `logs`에 최대 30개 보관합니다.
다른 PC로 옮길 때에는 기존 PC의 HDSign과 전광판 연결 도구를 종료한 뒤 새 PC에서 실행합니다.
`0x0 / status 129`가 뜨면 기기 잠금 암호를 확인합니다. 대시보드의 **기기 잠금 암호**에 현재 암호를 입력하고 **전광판 장치 인식**을 누릅니다.
암호는 이 PC의 연결 도구로만 전송되고 실행 중 메모리에만 유지됩니다. 파일·브라우저 저장소·송수신 로그·배포 ZIP에는 암호를 저장하지 않습니다.
도구 재실행 시 다시 입력합니다. 직접 실행할 경우 `WF4_DEVICE_PASSWORD` 환경 변수로도 지정할 수 있습니다.
이 코드를 성공으로 처리하거나 기존 접속을 강제로 해제하지 않습니다. 계속 실패하면 `logs`의 최근 오류 기록으로 확인합니다.

화면의 **기상정보 갱신**은 현재 산불 구역의 기존 기상 API를 다시 조회합니다.
원본 기상모델은 API가 안내하는 주기에 따라 갱신하며, 같은 관측값은 중복 송신하지 않습니다.
**장치 인식** 뒤에는 현재 최신값을 한 번 전송하고, 이후 새 관측값을 자동 전송합니다.
자동 송신을 해제해도 기상 조회는 계속됩니다. **전광판으로 보내기**로 수동 송신할 수 있습니다.
지연되거나 조회에 실패한 기상정보는 자동 송신하지 않습니다. 장치 오류 시 장치 인식을 다시 누릅니다.
브라우저에서 산불 서비스 화면을 닫으면 자동 갱신·송신도 종료되며, 마지막 스크롤은 보드가 계속 재생합니다.

소스 수정 후 배포 ZIP도 갱신합니다. 저장소 루트의 PowerShell에서:

```powershell
./tools/package-wf4-bridge.ps1
```

외부 의존성 없는 동봉 프로토콜 코드는 기존 WF4 시험 도구에서 확인된 HDSign UDP 송수신 및 저장 애니메이션 형식을 사용합니다.
